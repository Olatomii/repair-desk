# Start here

This is the first full-stack foundation for Repair Desk.

Recommended sequence:

1. Copy `.env.example` to `.env`.
2. Run `docker compose up -d`.
3. Run `npm install`.
4. Run `npm run db:generate`.
5. Run `npm run db:migrate -- --name init`.
6. Run `npm run db:seed`.
7. Run `npm run dev`.
8. Register a client account and create a repair request.

The GitHub repository is `Olatomii/repair-desk`. Use feature branches and pull requests for portfolio milestones.
